# did-it-reset

Did Claude or Codex reset today? Reads <https://toolsfordevs.app/resets.json>.

```sh
npx did-it-reset            # both
npx did-it-reset claude     # one vendor
npx did-it-reset --line     # one line, for a Claude Code statusline
```

Data and sources: <https://toolsfordevs.app> (live tracker, history, RSS and calendar alerts). "Today" is decided in UTC.
